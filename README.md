# 홍보 스튜디오

주야 님 앱들(Noraebang K, Click.moda AI, Rota Certa …)을 인스타·페북·틱톡에 홍보하는 개인용 안드로이드 앱.

- 인스타그램·페이스북 페이지: 예약 시간에 자동으로 올림 (Meta 공식 API, 본인 계정 전용)
- 틱톡: 시간 되면 알림 → 눌러서 틱톡 앱으로 보내기 (문구 자동 복사)
- AI 문구·해시태그: Google Gemini (포르투갈어/한국어)
- 앱별 홍보 관리, 팔로워·좋아요 성과 보기

main에 올리면 GitHub Actions가 APK를 만들어 Releases에 올림.
